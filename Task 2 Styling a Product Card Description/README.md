# Task 2: Styling a Product Card

## 📌 Project Description

This project involves designing a product card using HTML and CSS. The card displays a product image, product name, price, and an "Add to Cart" button. CSS is used to improve the layout, alignment, colors, and overall appearance.

## 🎯 Objectives

* Create a product card using HTML.
* Style the card using CSS.
* Display a product image, name, and price.
* Add an "Add to Cart" button.
* Implement hover effects for a polished user experience.
* Practice HTML and CSS fundamentals.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Clean and modern product card design.
* Product image with proper alignment.
* Product name and price display.
* Styled "Add to Cart" button.
* Hover effects and smooth transitions.
* Responsive card width for different screen sizes.

## 📂 Project Structure

```text
task-2-styling-a-product-card/
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Hover over the product card and button to see the effects.

## 📚 Learning Outcomes

This project helps develop practical skills in HTML structure, CSS styling, layout alignment, transitions, and hover effects.
