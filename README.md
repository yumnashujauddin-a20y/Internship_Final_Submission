# Internship Final Submission

## About This Repository

This repository contains the projects completed as part of my internship. Each task focuses on practicing web development concepts and building practical projects using HTML, CSS, and JavaScript.

### Task 2: Styling a Product Card Description
Practiced styling a product card and presenting product information using web design techniques.

### Task 3: Create a Responsive Webpage Layout
Created a responsive webpage layout designed to adapt to different screen sizes.

### Task 4: Build a Simple Quiz Application
Developed a quiz application to practice interactive webpage functionality and quiz logic.

### Task 5: Mini Project – To-Do List App
Created a to-do list application for organizing and managing daily tasks.

### Task 6: Real-World Simulation – Clone a Webpage
Built a webpage inspired by a real-world website to practice webpage structure, layout, and styling.
